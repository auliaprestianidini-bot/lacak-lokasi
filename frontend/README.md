# Phone Investigation Frontend

## Setup

```bash
npm install
npm run dev
```

Visit http://localhost:5173

## Features

- Phone number analysis
- Global map visualization
- Investigation timeline
- Report generation
- Dark/Light mode
- Responsive design

## Components

- PhoneSearchForm - Main search interface
- AnalysisResult - Display results
- GlobalMap - Map visualization
- InvestigationTimeline - Evidence tracker
- ReportGenerator - Report creation
- Navbar - Navigation
